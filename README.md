# CrazyCloud VPN

Быстрый VPN для Android: включается одним касанием, сам выбирает рабочий сервер и стабильно держит связь даже в мобильных сетях с ограничениями (VLESS Reality, XHTTP).

## ⬇️ Скачать

**[Последняя версия — раздел Releases](https://github.com/CrazyCloudApp/CrazyCloud/releases/latest)** → файл `crazycloud-*.apk`.

Основной сайт: [crazycloud.space](https://crazycloud.space) · Telegram-бот: [@getcrazycloud_bot](https://t.me/getcrazycloud_bot)

## Установка

1. Скачайте APK из [Releases](https://github.com/CrazyCloudApp/CrazyCloud/releases/latest).
2. Откройте файл и разрешите установку из этого источника, если Android спросит.
3. Запустите CrazyCloud и создайте аккаунт — номер телефона и почта не нужны.

Дальше приложение обновляется само.

## Возможности

- подключение одним касанием, пинг до каждого сервера;
- аккаунт без телефона и электронной почты;
- «Приложения без VPN» — банки и госуслуги напрямую;
- режим «РФ напрямую»;
- несколько устройств в одной подписке, подключение по QR-коду;
- оплата и живой чат поддержки прямо в приложении.
